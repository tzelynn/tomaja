# tomaja

A cute, chill, tomato-themed website for learning to read Japanese. Every kana, word and grammar
pattern is a plant; recalling it over days and weeks grows it from sprout to ripe tomato.

- Product spec: [specs/mvp.md](specs/mvp.md) · Build plan: [specs/implementation-plan.md](specs/implementation-plan.md)
- Stack: Svelte 5 SPA (PWA) + one Cloudflare Worker (Hono) + D1. All learning logic runs on the device.

## Develop

```sh
npm install
npx playwright install chromium        # once, for e2e tests and icon rendering
echo 'SIGNUP_CODE="any local code"' > .dev.vars
npx wrangler d1 migrations apply tomaja --local
npm run build                          # validate + build content, strokes, font, then vite build
npm run dev                            # or: npx vite preview (serves dist with the Worker)
```

| Command | What it does |
|---|---|
| `npm test` | Engine unit tests, 90-day learner simulation, Worker API tests against local D1 |
| `npm run test:e2e` | Playwright at 390×844: lessons, reviews, persistence, sync across two devices, axe |
| `npm run check` | Type-check app (svelte-check) and Worker (tsc) |
| `npx tsx scripts/validate-content.ts [--strict-audio]` | Content validation alone |

### Content

Hand-edited JSON in `content/`. Prerequisites are computed: a word unlocks when every kana in it
is learned; a grammar pattern when its words are. Validation fails the build if a word uses an
untaught character, a grammar tile is unknown, a mnemonic is missing or over 140 characters, etc.
Adding content is a data-only change.

### Audio

Clips are generated by hand, never in the build, and only clips a person has listened to ship:

```sh
# start VOICEVOX locally first (http://localhost:50021); needs ffmpeg
npm run audio:generate -- --only-kana --limit 46   # try the 46 basic sounds first
npm run audio:review                               # writes content/audio/review.html to listen
npx tsx scripts/review-audio.ts --mark あ い う …   # mark good clips as checked
```

Until a reading has a checked clip, the app falls back to the device's Japanese voice, and hides
the speaker button when neither exists. `validate-content.ts --strict-audio` fails while any
reading lacks a checked clip (spec success criterion 7).

## Deploy (https://tomaja.coodles.workers.dev/)

```sh
npx wrangler login
npx wrangler d1 create tomaja        # copy database_id into wrangler.jsonc; note the size limit → MAX_GARDENS
npx wrangler secret put SIGNUP_CODE  # the one secret code: use 4+ random words
npm run deploy                       # build → apply D1 migrations remotely → wrangler deploy
```

Syncing stays closed (503) until `SIGNUP_CODE` is set. Rotating it (`wrangler secret put SIGNUP_CODE`)
leaves gardens and signed-in devices alone. `MAX_GARDENS` (default 500) caps database use.
A daily cron removes expired sessions and stale throttle rows.
